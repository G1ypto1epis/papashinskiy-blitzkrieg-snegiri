ПАПАШИНСКИЙ БЛИЦКРИГ — «СНЕГИРИ»

Откройте index.html в браузере. Интернет не требуется.
Кампании: «Снегири наши!» — исходная операция; «Автобусный рубеж» — более сложная операция на другой карте с вооружёнными автобусами. Выбор доступен на стартовом экране и через кнопку ⚙. Выбор начинает новую миссию; перед этим можно сохранить текущую. Автобусы патрулируют позиции и оспаривают захват; маршрутки автоматически ведут ответный огонь.

На телефоне: коснитесь машины для выбора; «По типу» выделяет все видимые машины одного типа (сначала выберите одну машину), «Рамка» включает выделение прямоугольником одним пальцем; кнопка «Группы» выбирает колонну. Коснитесь местности для движения, флага — для захвата, здания — для обстрела. Перетаскивайте карту одним пальцем, сводите или разводите два пальца для масштаба. «☰» открывает цели, «Резерв» — подкрепления. Нижняя панель команд прокручивается горизонтально на узком экране. На компьютере сохраняется управление мышью и клавиатурой.

GitHub Pages: загрузите index.html в корень репозитория, откройте Settings → Pages, выберите Deploy from a branch, ветку main и папку / (root), сохраните и дождитесь адреса страницы.
