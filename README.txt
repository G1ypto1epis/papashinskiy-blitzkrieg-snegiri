ПАПАШИНСКИЙ БЛИЦКРИГ — «СНЕГИРИ», мобильная версия на основе v6

Откройте index.html в браузере. Интернет не требуется.

На телефоне: коснитесь машины для выбора; кнопка «Группы» выбирает колонну. Коснитесь местности для движения, флага — для захвата, здания — для обстрела. Перетаскивайте карту одним пальцем, сводите или разводите два пальца для масштаба. «☰» открывает цели, «Резерв» — подкрепления. Нижняя панель команд прокручивается горизонтально на узком экране. На компьютере сохраняется управление мышью и клавиатурой.

GitHub Pages: загрузите index.html в корень репозитория, откройте Settings → Pages, выберите Deploy from a branch, ветку main и папку / (root), сохраните и дождитесь адреса страницы.
